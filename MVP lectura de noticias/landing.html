Preguntas frecuentes
Todo lo que necesitás saber antes de comenzar.
¿Los modelos son realmente out-of-sample?
Sí. Usamos un split temporal estricto 80/20: entrenamos sobre el 80% histórico más antiguo y evaluamos sobre el 20% más reciente que el modelo nunca vio. El modelo de 90 días usa adicionalmente una ventana de 2 años de holdout para la calibración estacional, eliminando cualquier data leakage.
¿Qué activos cubre actualmente?
La versión actual está enfocada en soja (CBOT ZS=F). El roadmap incluye extensión a maíz, trigo y girasol en el próximo trimestre. Los planes PRO y Cooperativa incluyen acceso automático a los nuevos commodities cuando se lancen.
¿Puedo usar las señales directamente para trading de futuros?
Las señales son una herramienta de apoyo a la decisión, no asesoramiento financiero. Las métricas OOS honestas (54–72% de dirección según horizonte) son suficientes para decisiones de producción y cobertura, pero el trading especulativo requiere mayor conviction y gestión de riesgo propia. El módulo de paper trading te permite evaluar el rendimiento sin capital real antes de operar.
¿Con qué frecuencia se actualiza el dashboard?
El pipeline completo corre cada 6 horas. Los precios de mercado se actualizan con cada request. Los datos USDA (WASDE, China PSD) tienen un TTL de 24 horas. El brief semanal se genera automáticamente los lunes a las 8am.
¿Cómo funciona la integración API para cooperativas?
El plan Cooperativa incluye acceso a la API REST (JSON) con autenticación por API key. Podés obtener la señal actual, el forecast multi-horizonte y los datos de módulos individuales (basis, China, WASDE) con una simple llamada GET. Incluimos documentación y ejemplos en Python, Excel y Power BI.
¿Hay prueba gratuita?
Sí. El dashboard completo está disponible sin registro para evaluar las funcionalidades. La prueba incluye datos reales actualizados, el forecast activo y el historial de señales. Sin tarjeta de crédito requerida durante los primeros 14 días.
